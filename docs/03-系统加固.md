# 03 系统加固

服务器接入公网后很快就会被扫描，所以先做加固，再装代理。本章命令都以 root 在服务器上执行；用普通用户登录时，在命令前加 `sudo`。

> **防止把自己锁在外面**：改 SSH 和防火墙时，始终保留一个已登录的窗口。在另一个新窗口里测试能否登录，确认没问题再关旧窗口。

## 1. SSH：只允许密钥登录

新建一个独立的配置片段（比直接改 `sshd_config` 更好回退）：

```bash
tee /etc/ssh/sshd_config.d/99-hardening.conf >/dev/null <<'EOF'
PermitRootLogin prohibit-password
PasswordAuthentication no
KbdInteractiveAuthentication no
PubkeyAuthentication yes
EOF
sshd -t && systemctl reload ssh
```

`sshd -t` 检查语法，通过才重载。`prohibit-password` 表示 root 只能用密钥登录。然后在新窗口执行 `ssh root@<SERVER_IP>`，能登录再继续。

验证密码登录已被拒绝（本机执行，应提示 `Permission denied (publickey)`）：

```powershell
ssh -o PubkeyAuthentication=no root@<SERVER_IP>
```

## 2. 系统防火墙 ufw

```bash
apt install -y ufw
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp
ufw allow 443/tcp
ufw enable
ufw status verbose
```

80 端口平时不放行。做 iPhone 中继时，证书续期任务会在续期期间临时放行 80，结束后删除这条规则。8443 不用放行。

## 3. fail2ban：自动封禁暴力破解

Debian 12 默认没有 `/var/log/auth.log`（日志在 systemd journal 里），需要让 fail2ban 读 journal：

```bash
apt install -y fail2ban python3-systemd
tee /etc/fail2ban/jail.local >/dev/null <<'EOF'
[DEFAULT]
bantime  = 1h
findtime = 10m
maxretry = 5

[sshd]
enabled = true
backend = systemd
EOF
systemctl enable --now fail2ban
fail2ban-client status sshd
```

## 4. 自动安全更新

```bash
apt install -y unattended-upgrades apt-listchanges
dpkg-reconfigure -plow unattended-upgrades   # 选 Yes
systemctl status unattended-upgrades --no-pager
```

它只自动安装安全更新，不会升级 Xray（Xray 不是通过 apt 安装的，要手动升级）。

## 5. BBR + fq：改善高延迟线路的吞吐

```bash
tee /etc/sysctl.d/99-bbr.conf >/dev/null <<'EOF'
net.core.default_qdisc = fq
net.ipv4.tcp_congestion_control = bbr
EOF
sysctl --system
sysctl net.ipv4.tcp_congestion_control net.core.default_qdisc
```

两项分别输出 `bbr` 和 `fq` 即生效。

## 6. 流量统计 vnStat

```bash
apt install -y vnstat
systemctl enable --now vnstat
vnstat          # 刚装好时数据为空，过几分钟再看
```

vnStat 的统计跨重启持久保存；`ip -s link` 的网卡计数在重启后归零。两者起点不同，**计费以厂商面板的用量为准**。

## 7. 本章检查表

| 检查项 | 命令 | 期望 |
|---|---|---|
| 密码登录已禁用 | 本机 `ssh -o PubkeyAuthentication=no ...` | `Permission denied` |
| 防火墙已启用 | `ufw status` | `Status: active`，只放行 22、443 |
| fail2ban 在运行 | `fail2ban-client status sshd` | 显示 jail 状态 |
| 自动安全更新 | `systemctl is-active unattended-upgrades` | `active` |
| BBR | `sysctl net.ipv4.tcp_congestion_control` | `bbr` |
