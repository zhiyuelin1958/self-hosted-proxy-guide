# 03 系统加固

服务器接入公网后很快就会被扫描，所以先做加固，再装代理。本章命令都在服务器上执行。

> **防止把自己锁在外面**：改 SSH 和防火墙时，始终保留一个已登录的窗口。在另一个新窗口里测试能否登录，确认没问题再关旧窗口。

## 1. SSH：只允许密钥登录，禁止 root

新建一个独立的配置片段（比直接改 `sshd_config` 更好回退）：

```bash
sudo tee /etc/ssh/sshd_config.d/99-hardening.conf >/dev/null <<'EOF'
PermitRootLogin no
PasswordAuthentication no
KbdInteractiveAuthentication no
PubkeyAuthentication yes
EOF
sudo sshd -t && sudo systemctl reload ssh
```

`sshd -t` 检查语法，通过才重载。然后在新窗口执行 `ssh azureuser@<SERVER_IP>`，能登录再继续。

验证密码登录已被拒绝（本机执行，应提示 `Permission denied (publickey)`）：

```powershell
ssh -o PubkeyAuthentication=no azureuser@<SERVER_IP>
```

## 2. 系统防火墙 ufw

```bash
sudo apt install -y ufw
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 443/tcp
sudo ufw enable
sudo ufw status verbose
```

以后用到 8443、80（第 07 章）时再分别 `sudo ufw allow 8443/tcp`、`sudo ufw allow 80/tcp`。

## 3. fail2ban：自动封禁暴力破解

Debian 12 默认没有 `/var/log/auth.log`（日志在 systemd journal 里），需要让 fail2ban 读 journal：

```bash
sudo apt install -y fail2ban python3-systemd
sudo tee /etc/fail2ban/jail.local >/dev/null <<'EOF'
[DEFAULT]
bantime  = 1h
findtime = 10m
maxretry = 5

[sshd]
enabled = true
backend = systemd
EOF
sudo systemctl enable --now fail2ban
sudo fail2ban-client status sshd
```

## 4. 自动安全更新

```bash
sudo apt install -y unattended-upgrades apt-listchanges
sudo dpkg-reconfigure -plow unattended-upgrades   # 选 Yes
systemctl status unattended-upgrades --no-pager
```

它只自动安装安全更新，不会升级 Xray（Xray 不是通过 apt 安装的，见第 09 章的升级策略）。

## 5. BBR + fq：改善高延迟链路的吞吐

```bash
sudo tee /etc/sysctl.d/99-bbr.conf >/dev/null <<'EOF'
net.core.default_qdisc = fq
net.ipv4.tcp_congestion_control = bbr
EOF
sudo sysctl --system
sysctl net.ipv4.tcp_congestion_control net.core.default_qdisc
```

两项分别输出 `bbr` 和 `fq` 即生效。

## 6. 流量统计 vnStat

```bash
sudo apt install -y vnstat
sudo systemctl enable --now vnstat
vnstat          # 刚装好时数据为空，过几分钟再看
```

vnStat 的统计跨重启持久保存；`ip -s link` 的网卡计数在重启后归零。两者起点不同，**计费以云平台的用量记录为准**。

## 7. 本章检查表

| 检查项 | 命令 | 期望 |
|---|---|---|
| 密码登录已禁用 | 本机 `ssh -o PubkeyAuthentication=no ...` | `Permission denied` |
| 防火墙已启用 | `sudo ufw status` | `Status: active`，只放行需要的端口 |
| fail2ban 在运行 | `sudo fail2ban-client status sshd` | 显示 jail 状态 |
| 自动安全更新 | `systemctl is-active unattended-upgrades` | `active` |
| BBR | `sysctl net.ipv4.tcp_congestion_control` | `bbr` |
