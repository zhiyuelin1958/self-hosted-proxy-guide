# 01 准备与选型

## 1. 先写下你的需求

动手前回答这几个问题，它们决定后面每一步怎么选：

| 问题 | 示例回答 |
|---|---|
| 几个人用？几台设备？ | 1 人；1 台 Windows、1 部 iPhone、1 台 iPad |
| 主要用途？ | 网页、开发工具（编辑器插件、命令行工具）、手机 App |
| 是否有服务需要固定出口地区？ | 有一个服务希望固定在某地，需要二级出口 |
| 客户端关闭时是否允许直连？ | 指定服务不允许，需要防直连 |
| 入口被封时怎么办？ | 准备一条备用线路，指定服务在备用线路下直接失败 |
| 每月预算？ | 服务器约 10 美元；第二出口按月付费 |

把答案抄进计划进度测评模板的“计划”部分。

## 2. 入口服务器：地区与规格

**地区**：选离你近、到你所在网络线路好的地方。从中国大陆出发，日本、新加坡、香港和韩国通常延迟较低。同一地区里，不同厂商、不同运营商（电信、联通、移动和教育网）的表现差别很大。买之前，先用厂商提供的测速 IP 测一下 ping 和丢包。

**规格**：个人和少数几人使用，Xray 很省资源。

| 资源 | 建议 | 说明 |
|---|---|---|
| CPU | 1 核 | 只跑 Xray 和独立中继（Envoy）足够 |
| 内存 | 1 GiB | 同上 |
| 磁盘 | 16 GiB 以上 | 系统、日志和备份 |
| 系统 | Debian 12 / Ubuntu 24.04 | 本教程命令以 Debian 12 为准 |
| IPv4 | 必须是**静态公网 IPv4** | 客户端配置里写死了 IP，变了就要重新导入 |

**本教程示例**：新加坡 VPS，1 核、1 GiB 内存、16 GiB SSD，Debian 12，月费约 10 美元，每月流量 1 TiB。

**能否换 IP**：入口 IP 可能被整个封锁，表现为所有端口都不通，SSH 也连不上。重大会议、敏感日期前后，海外云厂商的机房 IP 常成片被封，几天到几周后陆续解封。选厂商时确认能在面板里自助更换 IP，并且面板有网页控制台（SSH 不通时用来核对主机指纹）。

## 3. 费用与流量

- 计费方式各家不同：大型云厂商多为**入站免费、出站计费**；很多 VPS 给每月固定流量，按入站、出站中**较高的一个**计算。下单前看清楚。
- 走代理时，同一份数据会经过服务器两次：从网站收进来（入站），再发给你（出站）。所以出站流量约等于你的总使用量。
- 走第二出口时，第二出口发回的响应也计入服务器入站。第二出口供应商一般也单独按流量或按月计费。
- 分流可以省流量：国内流量不经过服务器。
- 在面板设置流量或预算告警。

## 4. 第二出口（可选）

做二级出口需要一个支持 **SOCKS5（最好同时支持 UDP）** 的代理。常见的是供应商出售的“静态住宅 / ISP 代理”，或者另一台 VPS。选购时核对：

| 项目 | 为什么要问 |
|---|---|
| 是否静态、是否独享 | 动态或多人共享的 IP 出口会变，或者被别人的行为连累 |
| 地区与 ASN | 决定目标服务看到你在哪里、是什么网络 |
| 是否支持 SOCKS5 UDP | 实时语音、视频和 STUN 需要 UDP |
| 计费方式、续费价 | 流量包还是按月；续费是否涨价 |
| IP 来源说明 | 供应商宣称的“住宅”与各检测库的判断经常不一致 |

> 第三方检测站给出的“住宅 / 机房”分类和风险分只是参考，各库之间常有分歧，**不能代表任何服务对你账号的判断**。

## 5. 客户端

本教程用 [Clash Mi](https://github.com/KaringX/clashmi)。它基于 mihomo 内核，有 Windows、macOS、iOS 和 Android 版本，配置就是一个 YAML 文件，电脑和手机可以用同一份配置改出来。其他 mihomo 内核客户端（如 Clash Verge Rev）原理相同，只是界面路径不同。

> 版本兼容：服务端 Xray 和客户端内核都在快速迭代。本教程验证过的组合是 **Xray 26.7.28 + Clash Mi 1.0.32.1803（mihomo 1.19.33）**。升级任一端前，先在一台设备上验证握手，确认能回退再推广。

## 6. 备用线路（建议）

入口被封后，换 IP 和重新导入要花时间。可以在电脑上另备一个代理客户端（例如另一家机场的订阅），平时不运行。备用客户端和主客户端用同一个本地端口，浏览器、编辑器和终端的代理设置都不用改；两个客户端不能同时运行。

做了防直连的话，备用客户端里要**拒绝全部指定服务的域名和 IP 段**。这样指定服务只在主线路下可用，备用线路下直接失败，不会换出口。

## 7. 动手前的清单

- [ ] VPS 账号（已绑定支付方式、已设置流量或预算告警）
- [ ] 本机能用 `ssh`（Windows 10/11 自带 OpenSSH 客户端）
- [ ] 一个能临时访问 GitHub 的办法（首次下载 Xray、客户端和规则库时需要，代理搭好后就用不上了）
- [ ] 客户端安装包：Windows 从 Clash Mi 发布页下载；iPhone、iPad 需要非中国大陆区 Apple ID 在 App Store 安装
- [ ] （可选）第二出口的地址、端口、账号、密码
- [ ] 一个本地的、**不同步到公开位置**的文件，用来记录所有生成的密钥和链接
