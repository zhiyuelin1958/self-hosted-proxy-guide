# 01 准备与选型

## 1. 先写下你的需求

动手前回答这几个问题，它们决定后面每一步怎么选：

| 问题 | 示例回答 |
|---|---|
| 几个人用？几台设备？ | 2 人；2 台 Windows、2 部 iPhone |
| 主要用途？ | 网页、开发工具（编辑器插件、命令行工具）、手机 App |
| 是否有服务需要固定出口地区？ | 有一个服务希望固定在某地（→ 需要第 06 章） |
| 客户端关闭时是否允许直连？ | 指定服务不允许（→ 需要第 07 章） |
| 每月预算？ | 服务器尽量用免费额度；第二出口按月付费 |

把答案抄进 [templates/计划进度测评模板.md](../templates/计划进度测评模板.md) 的“计划”部分。

## 2. 入口服务器：地区与规格

**地区**：选离你近、到你所在网络线路好的地方。从中国大陆出发，日本、新加坡、香港和韩国通常延迟较低。同一地区里，不同厂商、不同运营商（电信、联通、移动和教育网）的表现差别很大。买之前，先用厂商提供的测速 IP 测一下 ping 和丢包。

**规格**：个人和少数几人使用，Xray 很省资源。

| 资源 | 建议 | 说明 |
|---|---|---|
| CPU | 1～2 核 | 突发型（如 Azure B 系列）足够 |
| 内存 | 1 GiB | 只跑 Xray 足够，加上第 07 章的中继（Envoy）也够用 |
| 磁盘 | 20 GiB 以上 | 系统 + 日志 + 备份 |
| 系统 | Debian 12 / Ubuntu 24.04 | 本教程命令以 Debian 12 为准 |
| IPv4 | 必须是**静态公网 IPv4** | 客户端链接里写死了 IP，变了就要重新导入 |

**本教程示例**：Azure Japan East，`Standard_B2ats_v2`（2 核 / 1 GiB），Debian 12，64 GiB SSD。Azure 免费账户首年对部分 B 系列规格、托管磁盘和出站流量有免费额度。具体规格和额度以 [Azure 免费账户说明](https://azure.microsoft.com/free/) 为准，开机前务必核对，避免超额计费。

## 3. 费用与流量

- 大多数云厂商**入站免费、出站计费**。你下载 1 GB，服务器要先从网站收 1 GB（入站），再发给你 1 GB（出站）。所以“出站流量”约等于你的总使用量。
- 走第二出口时，服务器和第二出口之间会多一份流量。服务器发给第二出口的请求很小；第二出口发回的响应计入服务器入站，转发给你时再计入出站。第二出口供应商一般也按流量或按月计费。
- 分流可以省流量：国内流量不经过服务器。
- 第 09 章介绍如何查看流量。建议在云平台设置**预算告警**。

## 4. 第二出口（可选）

要做第 06 章的二级出口，需要一个支持 **SOCKS5（最好同时支持 UDP）** 的代理。常见的是供应商出售的“静态住宅 / ISP 代理”，或者另一台 VPS。选购时核对：

| 项目 | 为什么要问 |
|---|---|
| 是否静态、是否独享 | 动态或多人共享的 IP 出口会变，或者被别人的行为连累 |
| 地区与 ASN | 决定目标服务看到你在哪里、是什么网络 |
| 是否支持 SOCKS5 UDP | 实时语音/视频、STUN 需要 UDP |
| 计费方式、续费价 | 流量包还是按月；续费是否涨价 |
| IP 来源说明 | 供应商宣称的“住宅”与各检测库的判断经常不一致（见第 08 章） |

> 第三方检测站给出的“住宅 / 机房”分类和风险分只是参考，各库之间常有分歧，**不能代表任何服务对你账号的判断**。

## 5. 客户端

本教程用 [Karing](https://karing.app/)。它有 Windows、macOS、iOS 和 Android 版本，基于 sing-box 内核，支持规则集（`.srs`）、按分流组设置 DNS 和 TUN。其他客户端（如 sing-box 官方客户端、Clash Verge Rev、v2rayN）原理相同，只是界面路径不同。

> 版本兼容：服务端 Xray 和客户端内核都在快速迭代。本教程验证过的组合是 **Xray 26.7.28 + Karing 1.2.25**。升级任一端前，先按第 09 章的方法验证握手是否兼容。

## 6. 动手前的清单

- [ ] 云厂商账号（已绑定支付方式、已设置预算告警）
- [ ] 本机能用 `ssh`（Windows 10/11 自带 OpenSSH 客户端）
- [ ] 一个能临时访问 GitHub 的办法（首次下载 Xray、客户端和规则库时需要，代理搭好后就用不上了）
- [ ] 客户端安装包：Windows 从 Karing 官网下载；iPhone 需要非中国大陆区 Apple ID 在 App Store 安装
- [ ] （可选）第二出口的地址、端口、账号、密码
- [ ] 一个本地的、**不同步到公开位置**的文件，用来记录所有生成的密钥和链接
