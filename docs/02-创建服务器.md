# 02 创建服务器

各家 VPS 的步骤大同小异：选地区、选系统、选规格、上传 SSH 公钥，然后开机。

## 1. 在本机生成 SSH 密钥

在 Windows PowerShell 中执行：

```powershell
ssh-keygen -t ed25519 -C "proxy-server"
```

一路回车即可，也可以设置口令。生成两个文件：

| 文件 | 用途 |
|---|---|
| `%USERPROFILE%\.ssh\id_ed25519` | **私钥**，只留在本机，绝不外传 |
| `%USERPROFILE%\.ssh\id_ed25519.pub` | 公钥，开机时上传给服务器 |

查看公钥内容（下一步要粘贴）：

```powershell
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub
```

## 2. 开机

1. 地区选目标地区，例如新加坡。
2. 系统选 Debian 12（或 Ubuntu 24.04 LTS），规格按需求选。
3. 登录方式选 SSH 公钥，粘贴上一步的公钥。面板不支持上传公钥时，先用面板给的 root 密码登录，再把公钥写进 `/root/.ssh/authorized_keys`。
4. 确认公网 IPv4 为静态地址。
5. 开机后在面板记下公网 IP，后文用 `<SERVER_IP>` 指代。

## 3. 放行端口

有的厂商在虚拟机之外还有一层云防火墙（安全组）。有的话，入站只放行下表端口；系统内的 `ufw` 也按这张表放行，两道都放行端口才通。

| 端口 | 协议 | 用途 | 何时需要 |
|---|---|---|---|
| 22 | TCP | SSH 管理 | 必需 |
| 443 | TCP | Xray（VLESS + REALITY） | 必需 |
| 80 | TCP | 申请、续期中继的 IP 证书 | 只在做 iPhone 中继时需要，续期时才临时打开 |

iPhone 中继的 8443 端口**不对公网开放**：它只在 VLESS 隧道内可达。

## 4. 第一次登录

```powershell
ssh root@<SERVER_IP>
```

首次连接会提示确认主机指纹，先和面板网页控制台里显示的指纹核对，一致再输入 `yes`。登录后先更新系统：

```bash
apt update && apt full-upgrade -y
reboot
```

重启后重新登录，接着做系统加固。

## 5. 可选：给 SSH 起个别名

在本机 `%USERPROFILE%\.ssh\config` 中加入：

```text
Host proxy
    HostName <SERVER_IP>
    User root
    IdentityFile ~/.ssh/id_ed25519
```

之后 `ssh proxy` 即可登录，脚本里也可以用这个别名。
