# 02 创建服务器

以 Azure 为例。其他厂商（AWS Lightsail、Vultr、搬瓦工等）的步骤大同小异：选地区 → 选系统 → 选规格 → 上传 SSH 公钥 → 开放端口。

## 1. 在本机生成 SSH 密钥

在 Windows PowerShell 中执行：

```powershell
ssh-keygen -t ed25519 -C "proxy-server"
```

一路回车即可（也可以设置口令）。生成两个文件：

| 文件 | 用途 |
|---|---|
| `%USERPROFILE%\.ssh\id_ed25519` | **私钥**，只留在本机，绝不外传 |
| `%USERPROFILE%\.ssh\id_ed25519.pub` | 公钥，开机时上传给服务器 |

查看公钥内容（下一步要粘贴）：

```powershell
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub
```

## 2. 创建虚拟机（Azure 门户）

1. 新建资源组，例如 `rg-proxy`，地区选目标地区（示例：Japan East）。
2. 创建虚拟机：
   - 名称：例如 `vm-proxy`；
   - 映像：Debian 12（或 Ubuntu 24.04 LTS）；
   - 大小：见第 01 章（示例 `Standard_B2ats_v2`）；
   - 身份验证类型：SSH 公钥，用户名例如 `azureuser`，公钥来源选“使用现有公钥”，粘贴上一步的内容；
   - 入站端口：先只允许 SSH (22)。
3. 磁盘：标准 SSD 即可。
4. 网络：确认公网 IP 为**静态（Static）**。Standard SKU 的公网 IP 默认就是静态的。
5. 创建完成后，在概览页记下公网 IP，后文用 `<SERVER_IP>` 指代。

## 3. 云防火墙（网络安全组）放行端口

Azure 的“网络安全组（NSG）”在虚拟机之外再挡一层。到虚拟机 → 网络 → 添加入站端口规则：

| 端口 | 协议 | 用途 | 何时需要 |
|---|---|---|---|
| 22 | TCP | SSH 管理 | 必需；可把“源”限制为你的常用 IP 段 |
| 443 | TCP | Xray（VLESS + REALITY） | 必需 |
| 8443 | TCP | iPhone 系统中继 | 仅第 07 章进阶部分 |
| 80 | TCP | 申请/续期 IP 证书 | 仅第 07 章进阶部分 |

> 只开需要的端口。后面第 03 章还会在系统内用 `ufw` 再设一道防火墙，两道都要放行，端口才通。

## 4. 第一次登录

```powershell
ssh azureuser@<SERVER_IP>
```

首次连接会提示确认主机指纹，输入 `yes`。登录成功后先更新系统：

```bash
sudo apt update && sudo apt full-upgrade -y
sudo reboot
```

重启后重新登录，进入第 03 章。

## 5. 可选：给 SSH 起个别名

在本机 `%USERPROFILE%\.ssh\config` 中加入：

```text
Host proxy
    HostName <SERVER_IP>
    User azureuser
    IdentityFile ~/.ssh/id_ed25519
```

之后 `ssh proxy` 即可登录，脚本里也可以用这个别名。
